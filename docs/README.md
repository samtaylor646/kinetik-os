# Kinetik-OS Documentation

This directory follows the strict AgencyOS hierarchy for managing documentation.

## Hierarchy

*   **`core/`**: The absolute source of truth containing core product requirements, project roadmaps, and pivotal strategy documents. ("North Star" requirements).
*   **`technical/`**: Architecture documents, API specifications, and technical implementation details.
*   **`operations/`**: Operational procedures, deployment guides, git workflows, and system maintenance playbooks.
*   **`qa/`**: Test plans, QA findings, test scripts, and quality assurance evidence.
*   **`archive/`**: Deprecated or superseded documents.

## 🚨 IMPORTANT RULE FOR ALL AGENTS 🚨

**Core Source of Truth Validation**: All agents MUST validate their approach against the documents located in `docs/core/` before initiating ANY work. This ensures all implementation aligns with the overarching product strategy, project roadmap, and core requirements.
